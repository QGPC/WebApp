Superuser only…

A reset returns the site to how it was before anyone used it, so you can start fresh before the Guild goes live. It works only while the site is in testing mode, so it can never be used by accident after launch. Last reset: never.

What a reset removes

InformationNow on the site

The Superuser account is never removed. Roles, the site log and the list of earlier resets are kept.

What to keep

All ticked is the usual choice. Untick something to clear it as well.

What a reset cannot do

It cannot take back emails that were already sent. It does not change anything in Zeffy (test payments stay there; mark or refund them in Zeffy). It does not touch the old Guild website, the Guild’s email or Google Drive. It cannot be undone from this page; the backup you download in step 1 is the only way back.

Step 1. Download a backup

The reset stays locked until a backup has been saved in the last 30 minutes. The file holds members’ personal information, so keep it somewhere private and password protected, and delete it when you no longer need it.

This backup holds all the information in the site’s tables (as a .json file). It does not include uploaded files such as photos, PDFs and newsletters. The full Backups tool, which includes files, comes later.

Step 2. Confirm and reset

    When the Guild is ready to start using the site for real.

    Going live switches the reset tool off for good. The site cannot be put back into testing mode from the website itself (it takes a deliberate change in the Supabase dashboard). Before you go live, make sure you have made a backup, loaded the real member list and checked the pages.
